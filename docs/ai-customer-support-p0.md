# AI 客服 P0 使用与验收说明

## 使用入口

进入自动化规则中的「AI 客服中心」。初次使用保持受控客服开关关闭，先准备公开知识、执行模拟测试，再选择是否启用。开关属于当前登录用户，对其名下店铺生效；原账号 AI 启停、商品覆盖和工作模式仍然有效。知识/FAQ 使用全场景客服模式，只有砍价模式时不直接发送普通 FAQ。

## 六项基础能力

- 三级知识：全局限当前本地用户，店铺限所属账号，商品限账号及商品。生成回复优先加入商品、店铺、全局公开事实，最多六条。每用户最多 60 条资料，单条正文最多 600 字符且配置总大小不超过 48 KB。
- FAQ：填写资料标题、问题和安全答案，保存后进行精确匹配（忽略大小写、首尾空白及末尾常见标点）。命中后直接利用已保存答案，无模型调用。相同范围内不允许重复问题。
- 沙盒：选择已有账号与可选商品，输入模拟买家问题。只生成候选或人工处理结果，不读取真实买家历史、发送聊天、改价、发货或写入正式会话；可能调用已配置的模型，产生该服务方的费用。
- 安全拦截与质量检查：对常见敏感链接、密钥、联系方式、退款赔偿承诺、越权要求、空回复、超长回复进行保守规则检查，砍价保留原价格边界。拒绝的文本不发送；风险转人工通知使用非敏感原因。规则不是完整 DLP、事实校验或提示词注入防护，可能误拦截或漏拦截，不应在公开知识中存放真正的私密交付资料。
- 人工接管：按账号、会话隔离持久化于现有用户设置表。主动人工回复按账号配置的时长暂停（未配置采用 30 分钟）；风险及控制台明确接管需要人工恢复。可以在中心查看记录、按会话 ID 接管、恢复和刷新。已进入网络发送的消息无法撤回，存储故障及进程重启组合下仍有状态丢失风险。
- 启用受控客服后，生成式原生 AI 与 FAQ 经过检查，外部 Agent 暂不参与受控链路；既有关键词、首次回复、默认回复和独立付款发货规则不属于生成检查范围，人工接管生效时暂停自动聊天回复，不改变交易自动化。

## 部署边界

复用 Go、React、现有用户设置仓储与兼容 OpenAI 的模型配置，不新增数据库迁移或第三方服务，不启用 Jev、不安装本地模型。管理员可根据现有网络地址安全策略使用已配置的兼容模型；FAQ 无模型费用，第三方模型可能按调用计费。基础版采用确定性匹配和有界事实拼接，不包含向量检索、文件导入、语义命中、跨进程接管互斥或 P1/P2 功能。

建议先使用模拟问题验证店铺隔离、正常 FAQ、价格边界、高风险转人工和明确恢复，再由商家决定是否在授权账号启用；不要用真实买家数据或秘密进行沙盒测试。此次开发不操作真实闲鱼账号，不改变登录、冻结 CAPTCHA 或自动发货顺序。

## 本机 Ollama 联调（2026-11-19）

- 系统设置：API 地址 `http://127.0.0.1:11434/v1`、模型 `qwen3.5:9b-q4_K_M`，无认证的本机 Ollama 服务可填写非秘密占位值 `ollama`（不要使用云端密钥）。以上配置由登录管理员在界面保存，不改变全局出站安全策略。
- 当前版本仅针对上述本机端点及 Qwen3.5 模型系列发送 `reasoning_effort=none`，正式客服请求温度为 0.3；其他端点保持原参数。系统连接测试同时发送非思考参数。
- 账号 AI 设置可先选择全场景模式，保持自动回复及自动改价关闭；先用客服中心沙盒验证实际商品规则，再由商家确认是否启用。首次装载模型较慢。
- 可显式设置 `RUN_LOCAL_OLLAMA_SUPPORT=1` 后执行 `go test ./internal/engine -run TestLocalOllamaCustomerSupport -count=1 -v`。该测试访问本机真实模型、使用临时数据库和虚构商品；不会访问闲鱼或对真实买家发送消息。
- 本次本机验收：七个模拟场景通过（四项模型回复、一项 FAQ、两项风险转人工）；新版二进制 26 项 HTTP 冒烟通过，含真实模型连接测试 602ms。未进行真实买家自动回复或生产账号交易验收；生产 AI 配置仍需管理员在网页保存。
