# 前端迁移映射与商品页纠偏记录

日期：2026-11-22。参考目录：`E:\ai_projects\xianyu-shop\shop-console-study`。

本记录区分参考页面的视觉结构与目标项目已有的真实业务能力。参考项目的演示数据和按钮不能直接作为生产接口能力。本轮重点验收用户指出的商品管理页及公共导航，不将其他页面的视觉一致性标记为已验收。

## 页面与功能映射

| 参考页面或功能 | 现有路由与业务入口 | 适配原则 |
| --- | --- | --- |
| `operations.js / home` 主页 | `/app/dashboard` | 沿用真实运营概览数据与会话权限 |
| `catalog.js / products` 商品管理 | `/app/items` | 参考筛选卡、状态标签、操作工具栏、商品表；保留同步、发布、编辑、规则和 AI 配置 |
| `catalog.js / bargains` 小刀商品 | 商品拍下改价规则、账号相关设置 | 复用原业务入口；不新增独立伪页面，不改变免拼与发货顺序 |
| `catalog.js / collect` 商品采集 | `/app/collector` | 保留已有采集、模板保存与异常反馈 |
| `catalog.js / drafts` 商品草稿 | `/app/library` 商品模板 | 可复用素材管理布局，但本地模板不等同于平台草稿 |
| `operations.js / orders` 订单 | `/app/orders` | 保留订单筛选、详情、同步与发货流程 |
| `operations.js / reviews` 评价 | `/app/rules` 评价赠品、求评价规则 | 复用已有规则，不新增不存在的评价列表接口 |
| `operations.js / stores` 店铺 | `/app/accounts` | 映射真实账号、授权、启停及自动化设置 |
| 统计类页面 | `/app/sales` | 保留真实统计口径，不使用参考项目演示金额 |
| `configuration.js / templates` 模板 | `/app/delivery-templates`、`/app/rules` | 发货模板与触发规则分别保留 |
| `configuration.js / images` 图片 | `/app/library` 图片库 | 沿用现有图片上传与资源引用 |
| `configuration.js / blacklist` 黑名单 | 现有客服与自动化规则配置 | 无独立页面的一一对应关系，不声称已迁移独立黑名单功能 |
| `configuration.js / notifications` 通知 | `/app/notifications` | 保留渠道、订阅和错误处理 |
| `configuration.js / logs` 日志 | `/app/logs` | 保留管理员权限与查询能力 |
| 原项目在线聊天、系统设置 | `/app/chat`、`/app/settings` | 保留原有能力及路由 |
| 原项目登录与首次初始化 | 原会话入口与初始化流程 | 继续使用原后端认证，不采用参考项目演示用户 |

## Agent 分工与交付

| Agent | 职责 | 实际交付 |
| --- | --- | --- |
| 主 Agent | 页面结构迁移、真实功能适配、构建启动、浏览器验证 | 商品筛选卡、表格与状态标签；公共顶栏和侧栏；构建资源与运行服务 |
| Carson，独立审核 Agent | 只读审查商品页状态映射、批量行为、接口边界与异常处理 | 发现未知货架状态被当作在售、删除副作用文案缺失、复制行为命名不准确及参考能力缺口 |

审核发现已纳入修正：全部商品与明确在售商品分开；删除确认说明本地记录和关联规则的影响；剪贴板操作命名为复制 ID。独立审核未触发任何平台写操作。

## 本轮商品页改动

- `ItemList.tsx`：取消旧大标题布局，使用蓝色提示条、独立筛选卡、状态标签和批量工具栏；保留原有账号选择、规则筛选、同步、发布、批量铺货与两种视图。
- `ItemTable.tsx`：使用参考表头、92px 行高、60px 商品图、红色价格、复选框和右侧固定操作列；编辑、单件上下架、删除、发货规则和 AI 设置继续使用原动作入口。
- `AuthenticatedShell.tsx`、`ConsoleTopbar.tsx`、`Sidebar.tsx`、`index.css`：180px 白色侧栏、50px 顶栏、分组菜单和参考配色。
- 发货标签仅统计生效的付款后发货规则，不把评价赠品、求评价或拍下改价视为自动发货。
- 状态未知的历史商品在“全部商品”中可见，只有平台回执确认上架的商品进入“出售中的商品”。
- 批量删除仍是本地记录删除，明确说明会影响关联自动化规则，并处理删除后列表刷新失败。
- 批量平台上下架未接入安全编排，按钮禁用；单件上下架继续使用原流程。前端不新增按商品循环请求平台的批量操作。

## 已知能力差异

| 项目 | 当前行为 |
| --- | --- |
| 曝光、浏览、想要、发布日期 | 接口缺字段，显示 `—`，不填演示数据 |
| 已售罄、定时上架 | 无对应真实字段，标签空态明确说明无法展示 |
| 售罄自动上架 | 禁用并标为“未接入” |
| 批量设置、批量上下架 | 禁用并提供原因；不计为功能已交付 |
| 批量复制 | 实际提供“批量复制 ID”，不声称复制商品或创建草稿 |
| 原有评价赠品、求评价配置 | 保留规则筛选及发货规则入口 |

## 验证边界

浏览器已检查真实商品展示、标题搜索、勾选状态、编辑弹窗及取消、商品 AI 设置读取及取消。对照用户参考截图核对了筛选卡、标签、操作条、表格密度、缩略图和价格样式。

没有为了测试向真实闲鱼账号执行发布、删除、上下架、发货或发送消息。自动化测试通过不等同于这些平台写操作已在真实账号上完成验收。其他页面仍需逐页截图对照后才能声称完整视觉迁移完成。
